Abyssus Dive Log

Save file explorer · reads Profile.sav locally

Drop your save file here

Everything runs inside this page. Your file is read in the browser and never uploaded anywhere.

Find it at:

%LOCALAPPDATA%\Abyssus\Saved\SaveGames\Profile1.sav

Close Abyssus first so the file isn't mid-write. Copy it somewhere safe rather than dragging the original, if you'd rather not touch the live save.


Read from the save file's own fields. Abyssus stores far more per run than its stats screen shows — accuracy, weakspot rate, damage by source, the node path you took, and every mutator rank.
